# 프로젝트 문서

## 현재 상태

2026-09-20 기준, 제품 설계와 CLI 인터페이스 문서 및 개발 환경 골격이 존재한다. 핵심 명령과 제품 훅은 미구현이다. 타입 검사는 통과했지만 테스트는 0개이므로 기능 검증 완료로 판단하지 않는다.

이번 문서 정리의 목표는 전체 구현 단계와 단계별 상세 계획을 작성하는 것이다. 사용자 지시에 따라 이 작업의 담당 범위는 문서 정리와 기획·설계 확정까지이며, 이 에이전트는 실제 제품 구현을 진행하지 않는다. 상세 계획은 다른 구현자가 이어받을 실행 기준으로 작성한다. 기획·설계의 새로운 결정은 사용자에게 질문하고, 답변 전에는 확정하지 않는다.

## 상세 계획을 위한 검토 목록

아래는 기존 문서에서 발견한 질문 대상이다. 해결안이나 구현 우선순위가 확정된 목록은 아니다.

| 주제 | 현재 문서의 내용 또는 공백 | 결정해야 할 사항 |
|---|---|---|
| 불완전한 엔트리 | Q01(B) 확정: 불완전한 기록도 원격 저장하고 부족한 내용을 명시한 뒤 보완한다. | 최소 내용은 결정·출처로 확정(Q07a). 표시는 메타데이터 목록·본문 설명으로 확정(Q07b). 목록은 missing 필수 배열(Q07c), 기본 검색 포함(Q13a)으로 확정. 대화 출처는 Context의 발언자·날짜·근거 요약(Q07d). 부분 누락 판정은 미결 |
| 자동 쓰기 | Q02 확정: auto_save 기본 true, PR 작업·조건부 세션 시작에 전송, false면 제안만. 기존 기록 동기화는 유지 | 네트워크·권한 전송 실패 시 코드 작업 허용(Q15a). 자동 저장 비활성 시 유효 초안이 있으면 코드 작업 허용(Q15b). 기타 실패와 기존 review 키는 미결 |
| 질문 게시 | Q03 확정: v1은 질문 내용·대상 개별 승인, 자동 게시 검토는 후속 | 질문 묶음·중복·답변 반영 세부 |
| 질문 중복 | PR당 코멘트 하나라는 원칙과 엔트리별 마커 중복 검사 규칙이 함께 있다. | 한 PR에 결정이 여러 개일 때 질문을 묶고 갱신하는 방법 |
| 확인 주체 | Q14a 확정: 결정자가 작성된 기록을 명시적으로 확인해야 verified_by를 채움. PR 머지·단순 답변은 확인 아님 | Q14b: 의미 변경 시 확인 해제. Q14c: 실제 확인자만 표시·전원 확인 불필요. 목록 원소·증거·변경 판정은 미결 |
| 상태 전이 | Q12a/b 확정: 모든 구현 PR 머지 시 accepted, 새 결정 accepted 시에만 기존 결정 superseded | Q12c: 전부 미머지 닫힘만 rejected, 일부 닫힘은 proposed·안내. Q12d: 재개방 시 proposed 복귀. 연결 변경·철회·다중 대체 등은 미결 |
| 대체 관계 | supersedes는 배열이지만 역방향 인덱스는 단일 id다. | 다중 대체, 순환, 존재하지 않는 대상의 처리 |
| 저장 실패 | rebase 후 push 1회 재시도와 로컬 커밋 유지가 정해져 있다. | 파일 충돌, 부분 성공, 재실행 중복 방지, 초안 삭제 시점 |
| PR 쓰기 모드 | 엔트리별 브랜치와 히스토리 PR을 생성한다. | 병합 전 조회, 수정, 코드 PR 상태 반영 및 병합 실패 처리 |
| 로컬 저장 | 캐시 경로 표현이 문서마다 다르며 브랜치명을 경로에 사용한다. | 경로 규약, 충돌 방지, worktree 및 브랜치 변경 처리 |
| 설정 | 설정 키 목록과 일부 기본값이 제시되어 있다. | 전체 스키마, 잘못된 값, 설정 없는 상태의 명령별 동작 |
| 소스 수집 | Q17 확정: 현재 작업 중심 조회, 상세 번들은 기록 시 수집, 전체 PR 검사는 명시적 요청·별도 활성화 | 조회 주기·한도, 누락 표시, 보존·삭제 규칙 |
| 검색 | BM25, 한국어 바이그램, 제목 가중치와 결과 형식이 제시되어 있다. | 점수 임계값, 동점, 상태별 취급, 평가 데이터와 통과 기준 |
| 훅 | 이벤트와 시간 제한이 제시되어 있다. | 명령 감지 범위, 내부 쓰기의 재진입 방지, 실패 시 차단 여부, 넛지 빈도 |
| 지원 환경 | TypeScript, Node, pnpm 및 양쪽 AI 도구 지원을 전제로 한다. | 지원 OS·최소 버전·호환성 검증 대상 |
| 배포 및 완료 기준 | 패키지와 매니페스트 골격만 존재한다. | 설치·업데이트·배포 경로, 단계별 인수 조건 및 출시 조건 |
