# 05. 인덱스·검색·관련 결정 조회

상태: 상세화 중. 관련 결정: Q08, Q12, Q13. 근거: [검색 설계](../spec/project-history-design.md), [조회 CLI](../spec/core-cli-interface.md).

## 목표와 산출물

후보를 결정적으로 줄이고 에이전트가 근거를 읽어 답하도록 한다. frontmatter 인덱스, 본문 검색 인덱스, search/show/related/index rebuild가 필요하다. 파생 인덱스는 히스토리 저장소에 커밋하지 않는다.

## 인덱스 계약

- by_id: id별 경로·제목·상태·날짜·결정자·확인자·missing 목록.
- by_ref: PR/이슈 URL별 엔트리 id 목록.
- by_path: glob과 엔트리 id 매핑.
- superseded_by: 이전 결정의 후속 결정. Q12a에 따라 proposed인 대체 제안만으로 기존 결정을 이미 대체된 것으로 안내하지 않는다. 다중 대체와 제안 관계의 별도 표현은 Q12에서 확정한다.
- questions: 엔트리·질문 URL·질문 시각. 댓글에서 파생하는 절차는 Q14와 연결한다.
- 전문 검색: title, Context, Decision, Alternatives. 한국어 바이그램과 영문 소문자 단어 토큰화, BM25, 제목 가중치 3.

라이브러리, 손상 엔트리 처리, 인덱스 버전·변경 감지·원자적 교체 규칙은 아직 미정이다.

## 명령별 계약

| 명령 | 기존 입력·출력 | 추가 결정 |
|---|---|---|
| search | query, repo, k 기본 10, min-score. candidates와 no_strong_match | 임계값 기본값, k 제한, 상태 가중, 동점, 저장소·경로 가산 |
| search 약한 매치 | no_strong_match와 nearest 최대 3개 | 빈 쿼리·0점·인덱스 없음·빈 저장소 |
| show | id, chain, json. 본문과 superseded_by/chain | 체인 순서·순환·미존재 id·분기 |
| related | 파일 목록, repo. entries와 matched | glob 문법, 경로 정규화, 중복·상태 필터 |
| index rebuild | 로컬 인덱스 재생성 | 상세 출력, 손상 파일, 질문 조회의 네트워크 범위 |

## 불완전한 기록의 검색 (Q13a 확정)

- missing 목록이 있는 기록도 기본 검색에 포함한다.
- candidates 및 nearest의 각 후보에 missing 배열을 반환한다. 부족함이 없으면 []다.
- 에이전트는 확인된 결정·근거를 답하고 질문에 필요한 내용이 missing에 해당하면 그 내용을 아직 모른다고 설명한다. 모르는 이유를 추측해 채우지 않는다.
- verified_by에 따른 미확인 표시와 missing에 따른 공백 안내를 구분한다. Q14a에 따라 내용이 모두 보완됐거나 PR이 머지됐어도 결정자의 명시적 기록 확인이 없으면 미확인이다.
- Q14b·Q14c: 일부 결정자의 확인만 있어도 실제 확인자를 표시한다. 기록의 의미가 바뀌어 기존 확인이 해제됐다면 이전 확인자를 현행 기록의 확인자로 표시하지 않는다. 확인 목록 변경을 인덱스와 응답에 반영해야 한다.
- refs가 없는 대화 기반 기록은 Context의 발언자·날짜·근거 요약을 출처로 설명한다(Q07d). 존재하지 않는 링크를 만들지 않는다.
- 불완전성에 따른 별도 감점·필터는 아직 정하지 않았다. 기본 검색 포함이라는 결정만으로 그런 정책을 도입하지 않는다.

## 에이전트 조회 흐름

질의 확장 → 상위 후보 최대 10개 → 1–3개 선택 → 본문과 현행 결정 확인 → 엔트리 id·refs·미확인 여부와 함께 답변한다. 매치가 약하면 기록 없음으로 답하고 관련 PR 백필을 제안한다.

## 확정 검색 정책의 검증

| 입력 기록·질문 | 기대 결과 |
|---|---|
| missing: [rationale], 관련 결정 검색 | 후보에 포함 가능하며 missing 전달 |
| 위 기록에 선택 이유 질문 | 결정 사실은 답할 수 있지만 이유는 미기록으로 명시 |
| missing: [], verified_by: null | 내용 공백 없음과 결정자 미확인을 구분 |
| 약한 매치의 불완전 기록 | nearest에도 missing 전달, 강한 근거처럼 답하지 않음 |
| 결정자 중 alice만 확인 | alice 확인으로 표시, 다른 결정자 확인을 주장하지 않음 |
| 의미 변경으로 기존 확인 해제 | 현행 기록 답변에 이전 확인을 재사용하지 않음 |

## 검증할 시나리오

한국어·영어·혼합어·대안 이름으로 검색, 제목 가중, 같은 점수의 순서, 현재 저장소 맥락, 대체된 결정의 현행 추적, 관련 파일 glob, 없는 기록, 인덱스 재생성 전후 결과 일관성을 다룬다.

문서의 검색 100ms 미만·전체 응답 1초 미만·토큰 목표는 측정 환경과 엔트리 수가 지정되지 않았다. 확정된 성능 시험 통과 기준으로 취급하지 않고 Q13에서 데이터·측정 범위를 정한다.
